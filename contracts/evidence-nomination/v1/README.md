# Evidence nomination v1 development contracts

Start with [CONTRACT.md](CONTRACT.md) for canonical identity, budgets, path
policy, reviewer boundaries, and downstream handoffs. [policy.json](policy.json)
contains machine-readable defaults and error vocabularies.

Five schemas describe the request, bundle, selection, claim candidate, and
component candidate. [Golden fixtures](golden/manifest.json) and
[templates](templates/) are synthetic examples, not a working search command.
The [approved plan](../../../docs/SEARCH_ASSISTED_CLAIM_MAINTENANCE_PLAN.md)
tracks the remaining implementation and release gates.
